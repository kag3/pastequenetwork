# PastequeGuard

Plugin de modération Spigot 1.9.4 avec sanctions, anti-spam/flood et panel de signalements.

## Commandes
- /pg report <joueur> <motif>
- /pg panel
- /pg ban <joueur> <raison>
- /pg tempban <joueur> <durée> <raison>
- /pg mute <joueur> <raison>
- /pg tempmute <joueur> <durée> <raison>
- /pg kick <joueur> <raison>
- /pg warn <joueur> <raison>
- /pg unban <joueur>
- /pg unmute <joueur>
- /pg history <joueur>

## Permissions
- pastequeguard.staff
- pastequeguard.bypass.chatfilter
