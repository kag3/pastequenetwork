# PastequeSkyBlockArena

Plugin Spigot 1.9.4 pour un monde d'arène séparé nommé `skyblockarena`.

## Fonctions
- Création automatique du monde `skyblockarena`
- `/arena` pour rejoindre l'arène
- Zones safe multiples configurables par admin
- Monde arène isolé : protection totale, admins bypass
- PvP actif, difficulté PEACEFUL, build interdit
- Messages de kill visibles uniquement dans le monde arène
- Niveau de 0 à 101 avec XP par kills et activité
- `/arenalevel` pour suivre progression, kills, morts, ratio
- `/arenakit` pour acheter un kit à 250 Pasteque
- Économie reliée au fichier `economy.yml` de PastequeSkyblock
- Combat logging : clear inventaire + perte de 500 Pasteque
- Chat global inter-mondes avec niveau arène en préfixe

## Commandes
- `/arena`
- `/arenalevel`
- `/arenakit`
- `/arenaadmin setspawn`
- `/arenaadmin safe pos1`
- `/arenaadmin safe pos2`
- `/arenaadmin safe create <nom>`
- `/arenaadmin safe delete <nom>`
- `/arenaadmin safe list`
- `/arenaadmin pasteque give|take|set <joueur> <montant>`
- `/arenaadmin stats <joueur>`
- `/arenaadmin reload`

## Permissions
- `pastequearena.admin`
- `pastequearena.bypass`
